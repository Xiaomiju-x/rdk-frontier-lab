# Community code of conduct

We welcome contributors with different backgrounds and experience levels.
Be respectful, explain disagreements with evidence, and separate a technical
result from a judgement about the person who produced it.

Harassment, threats, discriminatory language, deliberate disclosure of private
information and repeated disruptive conduct are not acceptable. Do not publish
another person's private data in an issue, benchmark fixture or example.

Maintainers may edit or remove harmful content, close disruptive threads and
restrict participation. Decisions should be proportionate and explained when
doing so does not expose private information. Contact the maintainer through
GitHub to raise a concern; request a private channel before sharing sensitive
details. There is no requirement to disclose personal information publicly.

This applies to project issues, PRs and other spaces officially maintained by
this repository. Honest failures, novice questions and evidence-based criticism
are welcome.
