# Roadmap

The research scope is long-lived; milestones describe acceptance criteria, not
promised delivery dates. Experimental work and publication work can be paused
independently.

## 0.1 · public foundation

- [x] Portable offline contracts, CLI, fixture integrity and numerical tools.
- [x] Runnable scalar demo and separately identified first-party geometry source.
- [x] Dated catalogue, source pins and accurate failure studies.
- [x] Contribution, security, release and publication checks.
- [ ] Independent external reproduction of the first public release.

## 0.2 · reproducible recipes

- [ ] Publish a small set of complete, license-cleared model recipes rather than
  equating every metadata entry with shipped implementation.
- [ ] Close the full TTM R3 native CPU deployment with its original identity and
  point/quantile semantics; do not substitute the older R2.1 model.
- [ ] Provide publicly shareable input sets and raw output subsets where rights allow.
- [ ] Add model-card evidence bundles validated against versioned schemas.

## 0.3 · comparable three-board results

- [ ] One algorithm with independent X5/S100/S600 artifacts, the same held-out
  fixture, unchanged task gates and identical timing boundaries.
- [ ] Labelled task evaluation, clean rebuilds and longer stability checks.
- [ ] Separate single-core, multi-core, concurrency and energy observations.
- [ ] Independent community reproduction; record differences instead of ranking
  incomparable runs.

## Not on the automatic roadmap

Unrestricted robot control, arbitrary dataset mirroring, redistributing proprietary
runtimes, evading model access gates, silently loosening failed thresholds, or
repeating a stopped recipe without a reviewed new research question.
