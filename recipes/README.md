# Recipes

Public code availability is separate from the historical catalogue.

- [Weighted Kabsch 6D geometry](weighted_kabsch_6d/README.md): real first-party
  algorithm source, optional NumPy execution, plus the original PyTorch scorer
  reference. No pretrained model or camera pipeline is bundled.
- [Board migration guide](../docs/migration.md): independent X5/S100/S600
  contracts and acceptance sequence, not an automated deployment script.

Other catalogue entries currently publish observations and references, not a
complete board recipe. Add a runnable recipe only after its dependencies,
licenses, target contract and evidence have been reviewed.
