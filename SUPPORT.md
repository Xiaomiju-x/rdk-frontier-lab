# Support

- **Getting started:** [quickstart](docs/quickstart.md), then [CLI/API](docs/api.md).
- **Model status:** [catalogue](docs/catalogue.md) and [limits](docs/limitations.md).
- **Bug:** open an issue using the bug template, with a synthetic reproducer.
- **New migration:** open a model request with exact source and target identity.
- **Security:** follow [SECURITY.md](SECURITY.md), not a public issue.

Provide the public package version and Python/platform family, but redact user
names, endpoints, credentials and private paths. Do not attach raw private logs.
For vendor SDK faults, include the exact public SDK version and a minimal example;
this project cannot provide proprietary binaries or vendor support guarantees.

Response times depend on maintainer availability. A catalogue entry is not a
promise to supply a checkpoint, finish a port or support a production deployment.
